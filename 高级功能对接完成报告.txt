🎯 使用方法
-----------------------------------------------------------------------------------

【人脸识别】
1. 在HTML中引入:
   <script src="face-recognition-api.js?v=1763712000"></script>

2. 使用示例:
   const imageData = await FaceRecognitionAPI.captureFromCamera();
   const result = await FaceRecognitionAPI.verifyFace('login', imageUrl);

【AI客服】
1. 在HTML中引入:
   <script src="ai-chat-api.js?v=1763712000"></script>

2. 使用示例:
   const aiChat = new AICustomerService('chatContainer');
   aiChat.open();

【Telegram绑定】
1. 在HTML中引入:
   <script src="telegram-api.js?v=1763712000"></script>

2. 使用示例:
   const bindUI = new TelegramBindUI('containerId');
   // 或直接访问页面: telegram-bind.html
